Сертификаты

Каждый сертификат подписывает NortInstall. Выберите активный — .ipa скачается напрямую из GitHub Releases. Не забудьте включить DNS-профиль, чтобы сборку не отозвали.

После установки: Настройки → Основные → VPN и управление устройствами → выберите сертификат → Доверять. Если сборка перестала открываться — сертификат отозван, возьмите другой активный из списка выше.
