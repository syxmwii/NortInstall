NortInstall

DNS-профиль NortInstall

Профиль включает DNS-over-HTTPS с блокировкой серверов Apple, которые отзывают сертификаты. Ставится один раз, удаляется после установки SideStore.

1. Создайте конфиг NextDNS

Зайдите на nextdns.io → Start free → создайте конфиг. В разделе Denylist заблокируйте домены:

ocsp.apple.com   ocsp2.apple.com   ppq.apple.com

Затем откройте Setup → Encrypted DNS → скопируйте ID из ссылки https://apple.dns.nextdns.io/ID/… (6 символов).

2. Соберите профиль

3. Установите профиль

  1. Скачайте файл в Safari на iPhone/iPad.
  2. Откройте Настройки → появится строка «Профиль загружен» → нажмите.
  3. Установить → введите код-пароль → Установить ещё раз.
  4. Готово: Настройки → Основные → VPN и DNS → должен быть выбран NortInstall DNS.

Как разрешить и проверить

  1. Профиль DNS не требует VPN-разрешений — iOS ставит его как конфигурацию.
  2. Проверка: откройте nextdns.io в браузере, конфиг покажет активность запросов.
  3. Сайты Apple открываются как обычно — блокируются только проверки отзыва сертификатов.
  4. Удаление после установки SideStore: Настройки → Основные → VPN и DNS → NortInstall DNS → Удалить профиль.
Зачем это нужно. Enterprise-сертификаты (как и свободные слоты Apple ID) проверяются Apple онлайн. ppq.apple.com и ocsp*.apple.com сообщают устройству, что профиль отозван — DNS-профиль не даёт этим запросам проходить, и приложение продолжает работать.
